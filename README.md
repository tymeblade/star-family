# star-family

Public schema documents for the star family.

- `/validator` — minimal forms modeled after schema.org for dumb validators
- `/ai` — forms and pointers for AI consumers (Anthropic-style and other AI-oriented schemas)

Working lock: JSON-LD 1.1. Destination target: JSON-LD 1.3 (JSON-LD-*).

Validator documents are suitable for direct submission toward schema.org-style registries. AI documents include minimal pointers for machine consumers.
